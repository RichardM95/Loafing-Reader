- 完整桌面 Release 构建成功，Slint 1.18.1 + Skia，原生阅读窗使用 DirectWrite / WIC / Win32 分层合成。
- 13 项测试通过，覆盖 UTF-8、UTF-16、GBK、Big5，章节规则和带标点标题，Unicode 连续分页，半透明像素，居中伪装文字，STA 兼容，托盘菜单，负坐标约束，独立透明度和配置覆盖保存。

## 无桌面输入的测量

本机同一份 TXT 的解码后 UTF-8 大小为 5,784,913 字节，自动识别得到 686 个候选章节。

| 测量入口 | 结果 |
|---|---:|
| Rust Release 读取、解码及章节识别 | 65.55 ms |
| Rust Release 单页排版与位图，200 次 p50 | 2.54 ms |
| Rust Release 单页排版与位图，200 次 p95 | 4.98 ms |
| Node 复现原版 UTF-8 读取、归一化与截取路径，50 次 p50 | 69.79 ms |
| Node 复现原版 UTF-8 读取、归一化与截取路径，50 次 p95 | 95.57 ms |

Rust 测量包含当前页排版和离屏位图，未包含键盘输入到显示器扫描输出的延迟。Node 复现未包含 lowdb 配置读取、IPC、Electron 或渲染。因此这些数据用于说明核心路径开销，不能直接解释为整机加速倍数。
